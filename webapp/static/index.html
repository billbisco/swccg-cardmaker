    How to use the Card Maker

    1. Pick a starting card with the search box (any Decipher or Players Committee card), or press New blank.
    2. Edit any field. The preview re-renders a moment after you stop typing.
    3. Art: the printed art (original or 4× upscale), the card's own scan, or upload your own picture.
    4. Download the PNG: 745 × 1039 is the Holotable / GEMP size; print size is 600 dpi.

    Codes in game text

    For AI assistants and batch work

    Export a card as JSON to see the format. POST /cardmaker/api/render with {"spec": …, "size": "holotable"|"master"|"preview", "format": "png"|"webp"} returns the image. GET /cardmaker/api/card/<gempId> returns any existing card as JSON; GET /cardmaker/api/search?q= finds cards.
