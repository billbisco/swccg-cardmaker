# Players Committee set marks (vector re-draws, card maker)

Drawn by `render.set_mark_html` (inline SVG) and exported here as transparent PNGs for anyone to use:
`pc-N` = Virtual Set N (blue ring; Set 0 gold), `pc-28`…`pc-40` = future Virtual Sets, `pc-D` = Virtual Defensive
Shields, `pc-P` = Virtual Premium, `vb-N` = 2009–2014 Virtual Blocks, `vb-D` = Virtual Block Shields.
Re-drawn to match the Holotable faces (font: Akzidenz-Grotesk BQ Condensed A — see FONTS.md for licensing).
